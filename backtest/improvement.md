### 改善 2: 買賣策略分離

**Before**: 買賣合一，策略同時產生 signal=1 (買) 和 signal=-1 (賣)
```
問題: RSI 策略在 RSI>70 時賣出，但強勢股 RSI 會高檔鈍化
      (長期維持 70+)，導致太早賣出，錯過大波段
```

**After**: 買入由 20 策略產生 signal=1；賣出由多層賣出策略獨立處理
```
買入: 策略 signal=1
賣出 (按優先順序):
  1. ⛔ 停損 — 保護本金
  2. 📉 移動停利 — 追蹤最高價回落
  3. 🎯 固定停利 — 鎖定利潤
  4. ⏰ 最大持有天數 — 避免套牢
  5. 📋 策略訊號 — signal=-1
  6. 📊 分批出場 — 可疊加
```

### 改善 3: 停損機制 (從無到有)

**Before**: 完全沒有停損機制。

**案例**: 台塑 1301 第一筆交易
```
2024-05-24 買入 64.29 (布林下軌 65.2)
   ↓ 持有 266 天，股價一路下跌
2025-02-14 賣出 37.86 (布林上軌已跟著下移到 37.7)
   → 虧損 -41.62% 🔴
```

**After**: 三道保險
```python
# engine.py _extract_trades()
if stop_loss > 0 and unrealized_return <= -stop_loss:
    force_sell = True  # ⛔ 停損
if take_profit > 0 and unrealized_return >= take_profit:
    force_sell = True  # 🎯 停利
if max_hold_days > 0 and hold_days >= max_hold_days:
    force_sell = True  # ⏰ 持有上限
```

**改善後的台塑案例** (停損 15%):
```
2024-05-24 買入 64.29
   ↓ 跌幅達 15% (約 54.6)
   ⛔ 停損觸發! 約 30~40 天後賣出
   → 虧損約 -15% (而非 -41.62%)
   → 資金提早釋放，可投入其他機會
```

### 改善 4: 移動停利 (Trailing Stop)

**Before**: 固定停利會太早賣出，錯過大波段

**案例**: 台積電 EMA 策略
```
固定停利 30%: 買入 500 → 漲到 650 (+30%) 立即賣出
   → 錯過後續漲到 800 的行情
```

**After**: 追蹤持倉期間最高價，從最高點回落 N% 才賣
```
移動停利 8%: 買入 500 → 漲到 800 (追蹤最高) → 回落到 736 (-8%) → 賣出
   → 獲利 +47.2%，遠超固定停利的 +30%
```

**實測結果** (台積電 + 聯發科):
| 方式 | 台積電報酬 | 聯發科報酬 |
|------|-----------|-----------|
| 固定停利 30% | +30% (只吃到第一波) | +30% |
| 移動停利 8% | +81% | +71.6% |

### 改善 5: 分批出場 (Partial Exit)

**Before**: 全倉進出，要嘛全賺要嘛全虧

**After**: 漲到不同階段分批出場
```
持倉 1000 股
  漲 10% → 賣出 333 股 (鎖定部分利潤)
  漲 20% → 賣出 333 股 (再鎖定)
  剩 334 股 → 跟蹤移動停利 (搏大波段)
```

**效果**: 既不會錯過大行情，又能鎖定利潤

---

### 改善 6: autoresearch 四階段最佳化

**Before**: 3 階段搜尋，固定次數限制
```
Phase 1: 掃描 → Phase 2: 網格 → Phase 3: 爬山
max_combos = 200，搜尋空間覆蓋不足
```

**After**: 4 階段不限搜尋
```
Phase 1: 全策略粗掃描 (20 實驗)
Phase 2: 全策略網格搜尋 (≤1000 全覽; >1000 隨機取樣)
Phase 3: 爬山法微調 (patience=50, 每步 8 鄰居)
Phase 4: 持續搜尋 — Top-5 輪流爬山 + 全局深度搜尋
         ▶ NEVER STOP 直到時間到或再無改善
```

| 對應 autoresearch | 回測最佳化 |
|-----------------|-----------|
| LLM 修改 train.py | 策略 + 參數組合 |
| val_bpb (越低越好) | win_rate (越高越好) |
| git commit → KEEP/DISCARD | 更新 best → KEEP / 不更新 → DISCARD |
| 5 分鐘 GPU 訓練 | 即時回測 (毫秒級) |

### 改善 15: BrokenPipeError 修復

**Before**: optimizer 的 print() 在 Streamlit subprocess 管道斷開時崩潰
```
BrokenPipeError: [Errno 32] Broken pipe
  File "optimizer.py", line 225, in _try_experiment
    print(f"  #{self.experiment_count:3d} [{strategy_name:15s}] "
```

**After**: 全局替換 print 為安全版本
```python
def _safe_print(*args, **kwargs):
    try:
        _original_print(*args, **kwargs)
        _sys.stdout.flush()
    except BrokenPipeError:
        pass

print = _safe_print
```
